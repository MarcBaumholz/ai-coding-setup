# Task brief template

Fill in the project-specific fields before use.

| Field | Content |
| --- | --- |
| Problem | What fails today, and for whom? |
| Expected behaviour | A concrete before-and-after example |
| Acceptance criteria | Test cases with observable results |
| Exclusions | Work outside the scope |
| Context | Repository, checkout, base/HEAD, relevant instructions and ADRs |
| Assumptions | What has been checked, and what needs a decision? |
| Write permissions | Exact paths; shared and unrelated files stay read-only |
| Review or verification | Who checks the work and what context they receive |
| Evidence | Test output, measurements, browser actions and environment |
| Stop conditions | Repeated failure, regression, round limit or missing prerequisite |
| Approvals | Decisions and external actions reserved for the owner |

## Completion report

Describe the result and the main changes. List completed checks with their evidence and remaining gaps. For unfinished work, give the next executable step and current checkout/revision. Keep proposed checks separate from completed ones.
