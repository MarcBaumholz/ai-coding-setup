# Project invariants

The private CoachBot invariants are omitted from this public export. Before using the factory, provide your own project baseline here. Read the repository instructions and verify the current facts.

Record:

- Runtime, framework and dependency versions.
- Ownership of data, permissions and shared/generated files.
- Required migrations and compatibility boundaries.
- CI, deployment, rollback and feature-flag behaviour.
- Allowed local and external actions, including commit, push and merge permissions.
- Locations of plans, decision records and evidence.

Missing project context remains unverified. Do not invent an environment or assume an external action is authorised.
